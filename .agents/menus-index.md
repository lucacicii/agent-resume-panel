# Feature Router Index

Agent Resume Panel is a local-first VS Code extension (`apps/extension/`) backed by its core library (`packages/core/`).

Use this index for feature requests without a concrete path or searchable identifier; read only the matching detail file.

## Cross-Cutting Locations

| Concern | Path | Notes |
| --- | --- | --- |
| Extension entry point | `apps/extension/src/extension.ts` | Registers views, commands, and refresh flows. |
| Extension locales | `apps/extension/locales/{en,zh-cn,ja}.json` | Extension UI strings. |
| Core public API | `packages/core/src/index.ts`, `packages/core/src/extension.ts` | Reusable domain logic behind this package boundary. |
| Extension package metadata | `apps/extension/package.json`, `apps/extension/manifest/base.{openvsx,marketplace}.json` | `package.json` is generated by `apps/extension/scripts/merge-extension-manifest.mjs`; regenerate menu blocks, never hand-edit them. |

Use `.agents/templates/menus-module.md.template` for new feature maps.
