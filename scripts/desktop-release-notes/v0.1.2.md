## Agent Resume Desktop v0.1.2

Localization and locale maintenance release.

### 新增 / Added

- **完整三语界面**：桌面端英文、简体中文、日文翻译已补全（以中文为基准校对）。
- **独立桌面语言包**：桌面端 locale 与 VS Code 扩展分离，仅包含 `desktop.*` 键，便于维护与打包。

### 改进 / Improved

- **语言覆盖检查**：新增 `i18n:check:translations` 脚本，可持续校验未翻译项。
- **日文 locale 流水线**：桌面端日文不再回退到英文，由 catalog 直接生成。

### 修复 / Fixed

- **macOS 打包**：修复重复执行 `pack:mac` 时 electron 符号链接冲突（`EEXIST`）。

### Install

1. Download `Agent Resume-0.1.2.dmg` from the assets below.
2. Open the DMG and drag **Agent Resume** to **Applications**.
3. If macOS blocks the app on first launch, right-click → **Open** once, or run:

   ```bash
   xattr -cr "/Applications/Agent Resume.app"
   ```

This build is ad-hoc signed and not notarized.
